## Introduction
This project provides a basic template for managing multiple Python libraries development in the template_library format.

## Usage

### Managing Multiple Libraries
This project provides a shell script `manager` to help manage multiple Python libraries. The libraries must be in lps_libraries.

- **install**: Commands to install (developer mode) and deploy (production - **todo**: List all TODO comments in the libraries.
- **count**: List the number of lines in each library.

### Installing

The project must specify which Docker environment to use or how to prepare it.

```bash
./manager install
```
